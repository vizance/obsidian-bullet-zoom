## Problem

1.12.0 的徑向選單在實機有兩個問題：每一格顯示指令全名，在小方塊裡被截斷、看不清楚是什麼；而且在最上層 Bullet 上長按時，圓環的左半邊會被螢幕邊界切掉，那些格子完全點不到。

## Root Cause

選單以觸控點為圓心，把格子平均分布在整個 360 度圓周上，沒有考慮可用空間；當觸控點靠近畫面左緣時，左半圓必然落在畫面外。格子內容使用指令全名，但每格寬度有限，長名稱只能截斷。

## Proposed Solution

- **改為扇形展開**：格子改成以觸控點為起點、朝畫面空間較大的一側展開的半圓弧。觸控點位於畫面左半時朝右展開，位於右半時朝左展開；弧線的垂直範圍會依觸控點與畫面上下緣的距離收斂，確保每一格都落在可視範圍內。
- **改用圖示**：每一格顯示圖示而非全名，圖示由呼叫端提供（外掛以 Obsidian 的圖示 API 依指令的圖示或設定的備援圖示繪製）；外掛自己的三個 Bullet 指令會註冊各自的圖示。
- **加上說明標籤**：選單中央附近顯示目前高亮那一格的指令名稱，滑到哪一格就顯示哪一格，解決純圖示的辨識問題；沒有高亮時顯示提示文字。
- **每個插槽加上開關**：插槽設定由單一指令字串改為「指令加啟用狀態」，設定頁每一格同時提供指令下拉與開關。關閉的插槽保留已選指令但不顯示，方便暫時收起而不必重選。讀取舊版的純字串設定時自動轉換為啟用狀態。
- **命中判定改為最近格子**：不再以角度換算，改為比較指標位置與各格中心的距離，取最近且在有效半徑內者；中央死區維持取消語意。這個方式與版面無關，扇形、半圓或任何排列都適用。

## Non-Goals

- 不改變長按時間、取消門檻與短按 Zoom 的行為。
- 不提供每一格自訂圖示的設定介面，圖示沿用指令本身的圖示與備援。
- 不支援超過八格或巢狀選單。

## Success Criteria

- 在最上層 Bullet（觸控點貼近左緣）長按時，所有格子都在畫面內且可點選。
- 每一格顯示圖示，滑到某一格時中央顯示該指令名稱。
- 觸控點靠近右緣時選單朝左展開。
- 滑到某格放開即執行該格指令，中央放開仍為取消。
- 關閉某個插槽後該格不再顯示，重新開啟時仍是原本選定的指令。
